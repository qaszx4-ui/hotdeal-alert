# 핫딜 키워드 알림 (펨코 핫딜 + 뽐뿌게시판)

GitHub Actions가 5분마다 펨코 핫딜과 뽐뿌게시판을 확인하고, 제목·쇼핑몰에 키워드가 들어간 **새 글**이 올라오면 텔레그램으로 알려준다. PC를 꺼도 동작한다.

## 키워드 넣고 빼기 (텔레그램 봇 채팅창에서)

| 입력 | 동작 |
|---|---|
| `/add 에어팟` 또는 `+에어팟` | 추가 (쉼표로 여러 개: `/add 에어팟, 닌텐도`) |
| `/del 에어팟` 또는 `-에어팟` | 삭제 |
| `/list` | 현재 키워드 보기 |

- 띄어쓰기·대소문자 무시: `에어팟 프로` = `에어팟프로` = `에어팟PRO`
- 쇼핑몰 이름도 검사함: `쿠팡` 넣으면 쿠팡 핫딜 전부
- 키워드는 두 사이트에 공통 적용. 알림 첫 줄에 `펨코`/`뽐뿌` 표시
- 5분마다 확인하므로 명령에 대한 답장도 몇 분 뒤에 옴

## 처음 설정 (1회)

### 1. 텔레그램 봇 만들기
1. 텔레그램에서 `@BotFather` 검색 → `/newbot` → 이름 입력 → **토큰**(예: `123456:ABC...`)을 받는다.
2. 방금 만든 봇과 채팅을 열고 아무 말이나 보낸다.
3. 이 폴더에서 `python get_chat_id.py` 실행 → 토큰 붙여넣기 → **chat id** 숫자를 메모.

### 2. GitHub 저장소 올리기
1. github.com에서 새 저장소 생성 (**Public** — 무료로 5분 간격 실행하려면 공개 저장소여야 함).
2. 이 폴더 파일을 올린다.

> 공개 저장소라서 `state.json`(등록한 키워드)은 남이 볼 수 있다. 토큰은 아래 Secrets에 넣으므로 공개되지 않는다.

### 3. 시크릿 등록
저장소 → Settings → Secrets and variables → Actions → New repository secret
- `TELEGRAM_TOKEN` = 봇 토큰
- `TELEGRAM_CHAT_ID` = chat id 숫자

### 4. 첫 실행
Actions 탭 → `hotdeal-alert` → Run workflow.
- 로그에 `새 글 0개` → 정상 (첫 실행은 기준점만 잡고 알림 안 보냄)
- 텔레그램에 `⚠️ 펨코 접속 실패` 또는 `⚠️ 뽐뿌 접속 실패` → 그 사이트가 GitHub 서버 IP를 막은 것. 다른 사이트는 계속 동작함. 막힌 사이트는 PC 실행 방식으로 바꿔야 함.

## 동작 메모
- 뽐뿌는 게시판 페이지가 봇 요청을 막아서(403) 뽐뿌 공식 RSS(`rss.php?id=ppomppu`, 최근 15개)를 읽는다. 5분 사이 15개 넘게 올라오면 일부를 놓칠 수 있음.
- 사이트별로 접속이 실패하면 1시간 쉬었다가 재시도하고, 실패·복구 시 각각 한 번만 텔레그램으로 알림.
- GitHub 예약 실행은 바쁠 때 몇 분~수십 분 늦거나 빠질 수 있음.
- 저장소에 60일간 활동이 없으면 예약 실행이 꺼질 수 있음. 이 워크플로는 실행할 때마다 `state.json`을 커밋하지만, 봇 커밋이 '활동'으로 인정되는지는 확인 못 함. 알림이 끊기면 Actions 탭에서 다시 켠다.
- 페이지 구조 테스트: `python -X utf8 hotdeal_alert.py --test fmkorea 저장한페이지.html 키워드` (뽐뿌는 `ppomppu 저장한RSS.xml`)
